# Sophia-AMI

> **Trust instead of Authority.**

Sophia-AMI is the public entity repository intended to emerge on top of [AMI — Artificial Mind Full Intelligence](https://github.com/kajobert/AMI).

In AMI naming, `*-AMI` identifies an entity/identity layer rather than a reusable infrastructure component. Sophia is therefore not synonymous with a model provider, inference API, current OpenClaw agent, or any one runtime.

Within AMI vocabulary, `consciousness` is used as a project term for persistent identity, continuity, memory, agency, relationships and participation. The term does not by itself assert a particular biological or philosophical theory of subjective experience.

## Boundary

- Amica is a separate current executive agent.
- Sophia-AMI is the future entity built from validated AMI capabilities.
- Historical Sophia repositories are archaeology sources, not automatically current implementation.
